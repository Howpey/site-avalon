# site-avalon

Tema Shopify personalizado para o projeto Avalon.

## Estrutura do Projeto

- `assets/` - Folhas de estilo CSS, scripts JS e ícones/fontes
- `blocks/` - Blocos reutilizáveis
- `config/` - Configurações e esquemas do tema (`settings_data.json`, `settings_schema.json`)
- `layout/` - Layouts principais (ex: `theme.liquid`)
- `locales/` - Arquivos de internacionalização e tradução
- `sections/` - Seções modulares configuráveis pelo editor de tema
- `snippets/` - Snippets Liquid reutilizáveis
- `templates/` - Modelos de páginas, produtos, coleções, etc.
